# Review-driven roadmap

Work advances in reviewable checkpoints. A stage is not complete merely because
its initial implementation exists.

1. **Spell and talent correctness — in progress.** Destruction first:
   [catalog review](destruction-review.md), missing actions, pet/talent conditions,
   then user approval of priorities. Follow with Affliction, Frost and Blood.
2. **Personal ergonomics — planned.** Per-key reach ratings, modifier preferences,
   individual spell binding locks; review suggestions against the actual movement layout.
3. **Profile safety — planned.** Unsaved-change warnings, last opened file,
   recovery snapshots, undo/redo. Verify that switching or closing cannot silently
   discard a layout.
4. **In-game import — planned.** Small controlled 7.3.5 profile, mouseover macros,
   reimport, rollback and keyboard mapping verification.
5. **Practice and distribution — planned.** Weak-key practice, progress history,
   automated repository checks and downloadable release packages.
